  1. Punto 1 · 1.25 ptsColor
    • La caja exterior debe tener border: 4px solid #008CBA y background-color: #E6F2F5.
    • El título debe tener color: #008CBA.
    • La etiqueta final debe tener background-color: hsl(190, 70%, 45%) y color: white.
  2. Punto 2 · 1.25 ptsTipografía
    • El título "Sobre Nosotros" debe tener font-size: 20px y font-weight: bold.
    • El párrafo debe tener font-size: 14px y line-height: 1.6.
    • La etiqueta debe tener font-size: 12px.
  3. Punto 3 · 1.25 ptsModelo de caja
    • La caja exterior debe tener width: 400px con box-sizing: border-box, border-radius: 10px y padding: 25px.
    • La etiqueta debe tener padding: 5px 12px, border-radius: 15px y display: inline-block.
  4. Punto 4 · 1.25 ptsEstructura y Layout
    • El orden dentro de la caja debe ser: título → párrafo → etiqueta.
    • La etiqueta debe tener margin-top: 10px respecto al párrafo.
